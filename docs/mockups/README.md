# FluxPOS — Mockups

Maquetas de la interfaz hechas solo con **HTML, CSS y JavaScript** (sin frameworks ni backend).
Los datos son de ejemplo. Para verlas, abre `index.html` en el navegador (doble clic).

| Archivo | Pantalla | Historias |
|---|---|---|
| `index.html` | Inicio de sesión | HU-01, HU-03 |
| `dashboard.html` | Resumen general | — |
| `productos.html` | Catálogo, búsqueda, filtro por categoría, alta/edición | HU-04 a HU-06 |
| `inventario.html` | Existencias, alertas, movimientos y ajustes | HU-09 a HU-11 |
| `ventas.html` | Nueva venta (carrito, validación de stock), historial y detalle | HU-16, HU-18, HU-19, HU-22 |
| `compras.html` | Historial y registro de compras | HU-20, HU-21 |
| `clientes.html` | Listado, búsqueda y alta | HU-12, HU-13 |
| `proveedores.html` | Listado y alta | HU-14, HU-15 |

Estructura: `css/styles.css` (estilos compartidos) y `js/app.js` (interacciones: paneles, pestañas, filtros, carrito).
